# Auditoría de dependencias de PR-00

El 30 de octubre de 2026 se ejecutaron las auditorías con pnpm 10.34.9 y el lockfile del proyecto. La consulta inicial dentro del sandbox falló por DNS; las repeticiones con elevación sí consultaron npm.

- `pnpm audit --prod --json`: cero avisos.
- `pnpm audit --json`: nueve avisos (uno crítico, cuatro altos, tres moderados y uno bajo); salida 1. No se presenta como auditoría limpia.

La severidad del registro no equivale a prioridad de revisión: estas rutas pertenecen al tooling, no al JavaScript del portal publicado. El análisis de alcance siguiente procede de la configuración local y las condiciones de cada aviso; no se ejecutaron exploits.

Antes de exponer servidores de pruebas, aceptar contenido externo o generar PDF/descargar navegadores con Marp, hay que reevaluar estas condiciones. No se añaden supresiones de auditoría.
