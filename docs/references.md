El contenido del ejemplo enlaza además las especificaciones [HTML](https://html.spec.whatwg.org/multipage/custom-elements.html) y [DOM](https://dom.spec.whatwg.org/), y las guías de propiedades/eventos de Lit. Las Skills de accesibilidad remiten a WCAG y WAI-ARIA APG; son referencias de trabajo para las siguientes revisiones, no una declaración de conformidad alcanzada.

La revisión final contrastó la configuración de navegación con la [guía oficial de sidebar de Starlight](https://starlight.astro.build/guides/sidebar/): los grupos con etiqueta contienen la configuración `autogenerate` dentro de `items`.
