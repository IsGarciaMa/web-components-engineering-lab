# Solución · Básico · Controlar el contrato

Configura items antes de interactuar, usa selected como ID y retira disabled para habilitar. connectTabs muestra una suscripción con validación de payload y devuelve su limpieza; también puedes usar el componente sin escuchar eventos si solo necesitas control externo.

Fuente: `src/examples/dom/tabs-consumer.ts`. Pruebas: `tests/unit/dom-tabs.test.ts` y `tests/e2e/working-with-dom.spec.ts`.
