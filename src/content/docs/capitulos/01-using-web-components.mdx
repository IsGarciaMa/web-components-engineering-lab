## Qué vas a aprender

Usar un Web Component consiste en comprender una API de navegador y un contrato de biblioteca, no en reimplementar su interior. Aquí adoptarás el papel de consumidor: de dónde viene la etiqueta, qué datos acepta, cómo notifica acciones y qué parte de su apariencia puedes cambiar.

Al terminar podrás elegir entre HTML nativo y una biblioteca, configurar atributos y propiedades, personalizar tokens y partes, observar el registro tardío y justificar una integración cliente con React o Astro. Distinguirás contenido HTML entregado por el servidor de comportamiento registrado en el navegador.

## Antes de empezar

Necesitas HTML semántico, CSS básico, módulos JavaScript y saber usar eventos. TypeScript ayuda a descubrir contratos; no aporta validación en tiempo de ejecución. Si quieres una comparación inicial entre estándar y Lit, lee [Un contrato, dos contadores](/guias/contador/).

No necesitas implementar un Custom Element desde cero para seguir el capítulo. El código de los componentes está disponible para consulta, pero su construcción en profundidad corresponde a entregas posteriores. PR-03 ampliará conversiones, reflexión y contratos.

## Cómo estudiar

1. Lee el objetivo y predice lo que ocurrirá en la demo.
2. Cambia una variable cada vez y compara el resultado observable.
3. Abre el código real del consumidor; identifica qué API llama.
4. Responde la pregunta de entrevista sin memorizar sintaxis.
5. Resuelve [los ejercicios progresivos](/ejercicios/using-web-components/) antes de desplegar sus soluciones.

El progreso local es una autoevaluación voluntaria por lección. No confirma haber dominado los conceptos ni publica información fuera de tu navegador.
