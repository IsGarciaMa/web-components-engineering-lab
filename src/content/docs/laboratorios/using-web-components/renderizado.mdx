## Cómo verificar el aprendizaje

Predice el resultado, cambia una entrada y explica qué parte pertenece al navegador y cuál al contrato del componente. Compara el estado visible con el código real desplegable. Si no coincide, consulta consola y registro antes de cambiar la implementación.

No hace falta editar código para esta demostración. Para practicar cambios propios, sigue [los ejercicios](/ejercicios/using-web-components/). Las verificaciones de CSS y teclado requieren un navegador real; leer el código no acredita esos resultados.
