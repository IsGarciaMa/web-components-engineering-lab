## Experimento principal

Empieza por [Lifecycle Visualizer](/laboratorios/defining-web-components/lifecycle/) si necesitas comprender recursos y reconexión. El historial acotado contiene solo callbacks ejecutados; una señal de prueba permite demostrar que el listener externo se retira al desconectar. La adopción usa un documento inerte real.

No existe desregistro de nombres: para repetir un registro tardío desde cero recarga la página. El movimiento preservado y el built-in opcional muestran su disponibilidad en el navegador; el resto del portal sigue funcionando sin esas APIs.
