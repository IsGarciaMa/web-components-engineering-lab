## Objetivo

Una instancia puede vivir fuera del documento y reconectarse muchas veces. Predice el resultado antes de cada acción y compara tu predicción con el texto observable.

## Recorrido reproducible

1. Crea sin conectar y cambia label antes de insertar.
2. Conecta, emite una señal, desconecta y vuelve a emitir.
3. Reconecta y comprueba un incremento por señal; prueba movimientos y adopción.
4. Reinicia y repite: el historial guarda como máximo 20 callbacks reales.

## Buenas prácticas y errores frecuentes

Eliminar un nodo no retira automáticamente listeners instalados en window. Abre las fuentes del panel para seguir la llamada real. No edites nodos internos de un componente como sustituto de su API pública. Los resultados proceden de operaciones reales; no hay un editor de ejecución arbitraria.

## Accesibilidad y límites

Todos los controles usan elementos nativos, etiquetas y foco visible. Los resultados se presentan en texto; el historial de lifecycle se consulta como lista con scroll y teclado, sin anunciar automáticamente cada fila. Comprueba también zoom, tema y contenido largo. La revisión automática con axe y las pruebas de responsive están preparadas para CI; no sustituyen lectura con tecnología de asistencia.
